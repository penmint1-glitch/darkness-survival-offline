FONT LICENSING
==============

The APKs bundle one CJK face, installed into BOTH `assets/SeoulNamsanEB.ttf`
and `assets/arial.ttf` (the game may render a given label through either slot).

Face: **Noto Sans SC** (Regular), **subsetted** — 1,520 glyphs / 325,884 bytes per
slot (the upstream face has 30,890 glyphs / 8,331,336 bytes and is installed into
both slots, so 651,768 bytes uncompressed in total).
Upstream: https://github.com/notofonts/noto-cjk  (Sans/SubsetOTF/SC/NotoSansSC-Regular.otf)
Regenerate the subset with `tools/subset_font.py`.
Licence: **SIL Open Font License 1.1** — redistribution inside an application is
permitted, including for commercial use, provided the licence text is bundled and
the font is not sold on its own.

>>> ACTION REQUIRED BEFORE PUBLISHING: the OFL 1.1 text is not yet in this repo.
>>> Add it (the build machine had no reliable outbound network):

    curl -L -o docs/LICENSE-NotoSansSC.txt \
      https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE

History: an earlier build bundled a face taken from a pre-existing fan
localization — FZHuaLi-M14 (方正华隶). That is a **commercial** font by Beijing
Founder Electronics and would have required a paid licence to redistribute; it
has been removed.

Coverage notes
--------------
* Every character used by the Simplified-Chinese text table and the 330 Cocos
  Studio `.csb` layouts exists in this face — verified against the subset's cmap:
  0 missing for the text table (1,401 non-ASCII characters) and 0 missing for
  printable ASCII. The only earlier miss was U+200B (zero-width space), injected
  by the reference localization; those occurrences were stripped from the text
  table before subsetting.
* The native library contains 379 Hangul syllables in hard-coded strings. Noto
  Sans SC has no Hangul. This is **cosmetic, not a crash**: the game renders
  missing glyphs as blank, and the same gap existed in the previously shipped
  face. If those strings are ever seen on screen, either add Hangul to the face
  (Noto Sans CJK SC covers Chinese and Korean in one file) or translate them.
* Do NOT assume a missing glyph crashes cocos2d here. An earlier investigation
  blamed the font for a crash that was in fact caused by our own edits to the
  `.csb` layout files.

Swapping the face
-----------------
`tools/build_zh_apk.py` reads the font directory from the `DS_FONT_DIR`
environment variable, so changing the face needs no code change:

    mkdir -p myfont
    cp NewFont.ttf myfont/SeoulNamsanEB.ttf
    cp NewFont.ttf myfont/arial.ttf
    DS_FONT_DIR=$PWD/myfont DS_NO_CSB=1 python3 tools/build_zh_apk.py <so> <textdata> out.apk
