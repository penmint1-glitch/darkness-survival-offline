The Simplified-Chinese builds replace the game's bundled subset font with a
subset of **Noto Sans SC** (SIL Open Font License 1.1).

Upstream: https://github.com/notofonts/noto-cjk  (Sans/SubsetOTF/SC/NotoSansSC-Bold.otf)
Subset:   1415 glyphs, produced with fontTools/pyftsubset (--no-hinting --desubroutinize)

The SIL Open Font License 1.1 text was not fetchable from the build machine
(no reliable outbound network). **Before publishing, add the full OFL text here**,
for example:

    curl -L -o docs/LICENSE-NotoSansSC.txt \
      https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE

The OFL permits redistribution and subsetting provided the license accompanies
the font and the font is not sold on its own. Keep this file next to the APKs.
