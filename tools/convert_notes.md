# 繁体 -> 简体 转换说明

这批译文原先是用**繁体**写的，原因是旧字体（SeoulNamsanEB.ttf 的子集）只有 4888 个朝鲜汉字，
缺少大量简体字形。**现在字体已换成 Noto Sans SC（20976 个 CJK 字形，简繁全覆盖）**，
所以字形限制完全解除。

转换时请做两件事：

## 1. 转成自然简体中文
不仅仅是逐字转换，要保证读起来是地道的简体中文（用词、标点、语序）。

## 2. 把当初"因为缺字而被迫替换"的词恢复成自然用词
| 旧译（被迫） | 请恢复为 |
|---|---|
| 冒險（用于表达 game） | 游戏 |
| 鎖匙 | 钥匙 |
| 骸骨 | 骷髅 |
| 頭甲 | 头盔 |
| 儲存 | 存档 / 保存 |
| 捨棄 | 丢弃 |
| 翼魔 | 蝙蝠 |
| 喪屍 | 僵尸 |
| 畵面 | 画面 |
| 已啓動 / 請啓動 | 已启动 / 请启动 |
| 卽可 / 立卽 | 即可 / 立即 |
| 幷 | 并 |
| 絶 | 绝 |
| 爲 | 为 |
| 値 | 值 |
| 甁 | 瓶 |
| 説 | 说 |
| 査 | 查 |
| 氷 | 冰 |
| 呪 | 咒 |
| 調査 | 调查 |
| 詛呪 | 诅咒 |

| 何種 | 何种 |

## 3. 必须逐字节保留
- 颜色标签 `<C........>`（`<C` + 8 位十六进制 + `>`），位置与数量不变
- 格式符 `%s` `%d` `%%`，数量与位置不变
- 换行标记 `\n`（字面反斜杠 + n），数量不变
- 首尾空格与连续空格的数量

## 4. 术语
遵循 `zh/glossary_simplified.md`。
